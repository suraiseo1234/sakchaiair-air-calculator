# Sakchai Air – Air Cleaning Price Calculator

เครื่องคำนวณราคาล้างแอร์เบื้องต้นแบบ Static Web Application

## Demo

หลังเปิด GitHub Pages แล้ว สามารถเข้าใช้งานผ่าน:

`https://YOUR-GITHUB-USERNAME.github.io/sakchaiair-air-calculator/`

## Features

- คำนวณราคาล้างแอร์เบื้องต้น
- เลือกประเภทแอร์
- ระบุจำนวนเครื่อง
- Responsive รองรับมือถือ
- HTML / CSS / JavaScript ล้วน
- มี SEO Meta Tags
- มี Open Graph
- มี JSON-LD Schema
- ไม่มีระบบสร้าง Traffic อัตโนมัติหรือ Fake Visit

## Files

- `index.html` — หน้าเครื่องมือและ SEO markup
- `style.css` — ในเวอร์ชันนี้ CSS อยู่ใน index.html เพื่อให้นำไปใช้ได้ง่าย
- `script.js` — ในเวอร์ชันนี้ JavaScript อยู่ใน index.html เพื่อให้นำไปใช้ได้ง่าย

## วิธีเปิด GitHub Pages

1. สร้าง Repository ใหม่บน GitHub ชื่อ `sakchaiair-air-calculator`
2. Upload `index.html` และ `README.md`
3. เข้า Repository > Settings > Pages
4. เลือก Source เป็น `Deploy from a branch`
5. เลือก Branch `main` และ Folder `/ (root)`
6. กด Save
7. รอ GitHub สร้างเว็บไซต์
